# Python Concurrency Demo

A graphical application demonstrating different concurrency approaches in Python.

## Features

- **Four Concurrency Methods:**
  - Sequential execution
  - Threading
  - Multiprocessing
  - Asyncio
  
- **Three Task Types:**
  - CPU-intensive (matrix calculations)
  - IO-intensive (simulated delays)
  - Mixed tasks

- **Interactive UI:**
  - Adjustable parameters
  - Real-time system monitoring
  - Performance charts
  - Execution history

- **Educational Content:**
  - Detailed explanations
  - Performance comparisons
  - Best practice guidelines
